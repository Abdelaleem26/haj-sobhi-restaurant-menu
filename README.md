# مطعم الحاج صبحي | Haj Sobhi Restaurant

موقع منيو لمطعم مصري (مثال تخيّلي): واجهة عربية RTL مع زرار للإنجليزي، منيو بأقسام وصور أطباق حقيقية، ومواعيد وعنوان.

A single-page menu site for a fictional Egyptian restaurant. Arabic RTL first, English toggle, categorised menu with real food photos, opening hours and location.

## تشغيل المشروع
افتح `index.html` في المتصفح مباشرة. مفيش أي أدوات بناء. الخطوط بتتحمّل من Google Fonts (محتاجة إنترنت).

## تعديل المحتوى
كل النصوص والأسعار في أول `index.html` داخل المصفوفات `INFO` و`CATS` و`MENU` و`FAVS` و`T`. الأسعار بالجنيه المصري.

## حاجات تتغيّر قبل الاستخدام الحقيقي
- رقم الحجز في `INFO.phone` (حاليًا رقم وهمي).
- العنوان والمواعيد.
- مكان الخريطة (حاليًا مربع فاضي).
- أسماء الأطباق والأسعار والوصف.
